# Templates motywu potomnego `classic-fashion`

Motyw potomny dziedziczy wszystkie szablony Smarty (.tpl) z motywu bazowego `classic`.
W tym katalogu można umieszczać nadpisania wybranych szablonów (np. `catalog/_partials/miniatures/product.tpl`, `checkout/_partials/cart-summary.tpl`).
Wszystkie pliki nieumieszczone w tym katalogu są automatycznie ładowane z motywu nadrzędnego (`themes/classic/templates/`).
